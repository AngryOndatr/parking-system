# 🔗 GitHub Projects Board - Связь с проектом (Краткая версия)

> See also: [GITHUB_BOARD_VS_KANBAN_EXPLAINED.md](./GITHUB_BOARD_VS_KANBAN_EXPLAINED.md)

## 🎯 Главное

**Board автоматически связывается с репозиторием при создании!**

---

## 📊 4 способа работы

### 1. Issues → Board
```
Создаете Issue в репозитории
    ↓
Добавляете в Projects (справа)
    ↓
Issue появляется на Board
```

### 2. Board → Issues
```
Создаете карточку на Board
    ↓
Конвертируете в Issue
    ↓
Issue создается в репозитории
```

### 3. Pull Requests → Board
```
Создаете PR #30
    ↓
Связываете с Issue #25 ("Closes #25")
    ↓
PR автоматически на Board
```

### 4. Автоматизация
```
PR merged
    ↓
Issue закрывается автоматически
    ↓
Карточка перемещается в "Done"
```

---

## 🎬 Практический сценарий

```
День 1: Issue #23 "Add Flyway"
        ↓ добавляем в Board
        Board: [To Do] → #23

День 2: Начинаем работу
        ↓ меняем статус
        Board: [In Progress] → #23

День 3: Создаем PR #30
        ↓ связываем с #23
        Board: [Review] → #23, #30

День 4: PR merged
        ↓ автоматически
        Board: [Done] → #23 ✅
```

---

## ✅ Преимущества

- **Двусторонняя синхронизация** - изменения везде
- **Автоматизация** - меньше ручной работы
- **Единая картина** - вся команда видит прогресс
- **От задачи до кода** - полная трассируемость

---

**TL;DR:** Создаете Board в репозитории → он автоматически связан с Issues, PRs и коммитами. Всё синхронизируется в реальном времени!
